# 🏫 The Crane Academy Website

A simple and attractive website for **The Crane Academy**, a primary school located in Kitale, Kenya. This project features a responsive design with a slideshow, mission and vision sections, and contact information.



## 📁 Project Structure

```
The-Crane-Academy/
├── index.html        # Main HTML page
├── style.css         # CSS styles for layout and design
├── script.js         # JavaScript for slideshow functionality
└── images/           # Folder containing slideshow and school-related images
```

## 🎯 Features

- 🎨 Beautiful, responsive design
- 🖼️ Automatic slideshow with animated transitions
- ✏️ About Us section with Mission and Vision
- 📍 Contact Us section with location, email, and address
- 📱 Mobile-friendly layout

## 🚀 How to Use

1. Clone the repository or download the ZIP:
   ```bash
   git clone https://github.com/Masigacodes/the-crane-academy.git
   ```
2. Open the project folder:
   ```bash
   cd the-crane-academy
   ```
3. Open `index.html` in your browser:
   ```bash
   open index.html  # or just double-click the file
   ```

## 🧠 Technologies Used

- HTML5
- CSS3 (Flexbox, gradients, animations)
- JavaScript (for image slideshow)

## 🖼️ Images

Place your school images inside the `/images` folder and name them appropriately (e.g., `image_1.jpg`, `image_2.jpg`, `image_3.jpg`).
